🛡️ AI-Based Network Intrusion Detection System
<img src="https://img.shields.io/badge/Final_Year_Project-In_Progress-0E7490?style=flat-square" alt="Final-year project in progress" /> <img src="https://img.shields.io/badge/Not_Publicly_Released-334155?style=flat-square" alt="Not publicly released" />

An academic project proposal exploring how machine learning can help identify potentially malicious network traffic, classify attack categories, and communicate results through a clear security dashboard.

The proposed approach examines normal traffic and threats such as PortScan, Brute Force, DoS, DDoS, Botnet, and Web Attack, with understandable threat priorities for users reviewing alerts.

Areas involved: Network Security · Machine Learning · Traffic Classification · Security Dashboards
